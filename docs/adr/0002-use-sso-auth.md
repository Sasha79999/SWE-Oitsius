# ADR-0002: Використання SSO для авторизації

**Статус:** accepted

## Контекст
Замовник вимагає, щоб студенти заходили через корпоративну пошту. Вимога FR-001 та Domain-02 з ТЗ. Потрібно забезпечити безпеку та зручність.

## Рішення
Обрано технологію SSO (Single Sign-On) на основі домену @uni.edu. Це дозволить використовувати існуючі облікові записи університету без створення нових паролів.

## Наслідки
**Переваги:** Підвищена безпека (паролі зберігаються в університеті). Зручність для студентів (один вхід). Відповідність вимогам ТЗ.
**Компроміси (обмеження):** Залежність від стороннього IdP (Identity Provider) університету. Якщо сервер авторизації впаде, студенти не зможуть зайти на портал.
