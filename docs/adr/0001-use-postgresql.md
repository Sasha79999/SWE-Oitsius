# ADR-0001: Вибір бази даних PostgreSQL

**Статус:** accepted

## Контекст
Для порталу потрібно зберігати дані студентів, розклад та заявки. Вимоги з ТЗ: надійність, підтримка складних зв'язків (студенти, групи, предмети) та безкоштовність для державного закладу.

## Рішення
Обрано реляційну базу даних PostgreSQL (згідно з розділом «Технічні обмеження» ТЗ). Вона є open-source, добре інтегрується з Python/Java бекендом та підтримує шифрування даних.

## Наслідки
**Переваги:** Безкоштовна та надійна. Підтримка ACID-транзакцій (важливо для заявок на довідки).
**Компроміси (обмеження):** Складніше налаштування кластеризації порівняно з MySQL. Потребує адміністрування (резервне копіювання, оновлення).
