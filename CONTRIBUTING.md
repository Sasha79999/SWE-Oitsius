# Як працювати з репозиторієм

Цей документ описує правила роботи над проєктом.

## Назви гілок

Кожна гілка створюється під одну задачу з дошки.

- `feature/<опис>` для нової функціональності;
- `fix/<опис>` для виправлень.

Приклад: `Feature_Search`

## Повідомлення комітів

Формат: `тип: дія в наказовому способі`.

- `docs: додати опис проєкту`
- `ci: додати перевірку README`

Не використовуйте `update`, `fix`, `wip`.
